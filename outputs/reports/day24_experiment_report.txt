4. TEXT CHUNKING IMPROVEMENT

Previous approach: Character-based chunking.

Improved approach: Word-aware chunking.

Chunk size: Approximately 300 characters
Chunk overlap: Approximately 50 characters

The updated method moves chunk boundaries
to whitespace to avoid splitting words.

Total knowledge documents: 5
Total chunks generated: 10

5. RETRIEVAL OPTIMIZATION

Duplicate-document filtering was implemented.
Only the highest-scoring chunk from each
knowledge document is retained.

Hybrid retrieval combines:

- TF-IDF cosine similarity
- Keyword matching against technique names,
  descriptions and detection clues

Configured keyword boost: 0.15

Hybrid scoring formula:

Final Score =
(0.85 * TF-IDF Score) +
(0.15 * Keyword Score)

Analyst Guidance is excluded from keyword
matching to reduce irrelevant matches.

9. OBSERVATIONS

Hybrid retrieval improved Top-1 accuracy from
75% to 100% on the four-case test dataset.

Keyword matching helped correct the ranking
of the Valid Accounts test case.

Unique-document filtering prevented multiple
chunks from the same technique from occupying
the retrieval results.

Gemini successfully used the retrieved context
to explain the sample SOC alert.

10. LIMITATIONS

- Only four curated evaluation test cases.
- Knowledge base contains five MITRE techniques.
- Results do not establish real-world accuracy.
- Keyword matching is dependent on the curated
  knowledge base and token normalization.
- Word-aware chunking does not guarantee
  semantic chunk boundaries.
- Precision and recall depend on the defined
  single-expected-technique test labels.
- Gemini output requires human verification.
- No production or real-time SOC deployment tested.

11. CONCLUSION

Day 24 improved the RAG pipeline through
word-aware chunking, unique-document filtering
and hybrid TF-IDF plus keyword retrieval.

The evaluation achieved 100% Top-1 accuracy
on the four curated test cases, compared with
75% using the baseline TF-IDF retriever.

Gemini integration was also validated using
the hybrid retrieval results.

These findings demonstrate improvement on
the current experimental dataset. Broader
testing is required before drawing conclusions
about real-world SOC performance.
